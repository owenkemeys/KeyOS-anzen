`regtest-proposal.json` is a development-only, phone-signed Anzen policy proposal generated by Luke Childs' unmodified Rust library at upstream commit `01794bb14d34d01413e3b539c7e5496ecbce0c87`.

The generator used deterministic regtest-only phone and HWW identities, a fake 2 BTC vault UTXO, 0.1 BTC monthly allowance, 0.5 BTC emergency access, twelve allowance authorization/revocation pairs, and the same `build_policy_proposal` plus `package_from_batch` path used by Luke's CLI. The fixture's HWW x-only key is `906979e124fa1d21104bbcfce84d825cb1269fa1dc95a0a27e9bfe120d88e97c`; it is derived from the development app-seed vector `[0x42; 32]` through Luke's BIP39/BIP32 vault-key path.

The JSON is 50,485 bytes with SHA-256 `e54ac6aa0738ee833982368fa673e3b59ba46a5f047f334c18321143b17c3c62`. It contains no mnemonic, seed, extended private key, or live wallet data.

This fixture proves compatibility with Luke's package construction and phone signatures. It is not evidence of a live phone transport, Bitcoin Core acceptance, Passport Prime execution, physical hardware execution, mainnet safety, or funds movement. The separate regtest round-trip script owns the unchanged-CLI activation proof.
